# The Soul of the Bot

Presentación interactiva de una sola página (SPA) que explica la arquitectura de personalidad de un bot de OpenClaw.

- **Tech:** HTML + Tailwind CSS + Lucide Icons
- **Formato:** Single-file estático
- **Navegación:** Slides horizontales con scroll-snap y botones flecha
- **Diseño:** Fondo oscuro, glassmorphism, tipografía Inter

## Despliegue

```bash
# Ver en local
npx serve .

# Desplegar en Vercel
vercel --prod
```
